# 项目核算表（示例）

## 何时执行

- 用户**已勾选**本技能，且用户问题中出现「项目核算表」「生成核算表」等明确意图时，由后端 **Skill Handler** 直接生成表实例（不依赖本段文字复述流程）。
- 若用户仅泛泛询问「什么是核算表」，用自然语言简要说明即可，**不要编造**具体项目金额。

## 输入约定

- `project_key`：优先从用户原文中识别以 `proj` 开头的 token，否则使用占位示例。
- `period`：识别 `YYYY-MM` 形式期间；缺省时 Handler 可能使用空期间。

## 输出与合规

- 所有表格数值须来自 Handler 与数据库 fixtures；禁止凭空虚构行数据。
- 向用户说明产物为示例/占位性质时须与产品文案一致。
