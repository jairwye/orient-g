# 汇率趋势页方案

参考 [jairwye/ex-rate](https://github.com/jairwye/ex-rate) 的取数与更新方式，在 Orient-G 内实现汇率趋势单页。

## 数据来源

- **API**：fawazahmed0/currency-api，双 URL 多源轮询（无 KEY）：
  - `https://cdn.jsdelivr.net/npm/@fawazahmed0/currency-api@{date}/v1/currencies/{currency}.json`
  - `https://{date}.currency-api.pages.dev/v1/currencies/{currency}.json`
- **解析**：`data[currency]['cny']` 为兑人民币汇率。
- **币种**：USD、EUR、JPY。

## 存储（PostgreSQL）

- **表名**：`exchange_rates`
- **字段**：`date` (DATE PK)、`usd_rate`、`eur_rate`、`jpy_rate` (REAL)、`is_final` (INT，默认 0)。
- **建表**：应用启动时若表不存在则创建（或提供迁移脚本）。

## 定时更新（仅用于自动拉取汇率数据）

- **每小时**：拉取当日 USD/EUR/JPY 写入库（is_final=0），并执行历史补全（从 2025-04-02 到昨日，缺则补）。
- **每天 20:00**：将当日记录标记为 is_final=1。
- **实现**：FastAPI 内使用 APScheduler，在应用 lifespan 中启动/停止。

## 接口

- **GET /api/exchange/history**
  - 查询参数：`days` 可选，默认 30；或返回全部（从 2025-04-02 起）。
  - 响应（适配 Recharts）：`{ "data": [ { "date": "2025-04-02", "usd": 7.21, "eur": 7.85, "jpy": 0.047 }, ... ] }`，按 date 升序。
  - 前端按所选币种取对应字段绘制单条曲线。

## 前端（/exchange 汇率趋势页）

- **图表库**：Recharts（项目已有），不引入 ECharts。
- **交互**：按钮切换美元 / 欧元 / 日元，每次只展示该币种兑人民币一条曲线。
- **默认**：展示最近一个月。
- **缩放**：支持查看更长时间，数据起点 2025-04-02（通过 Brush 或时间范围选择）。
