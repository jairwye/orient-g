## 1. 设计原则（相对旧矩阵的变化）

| 旧问题 | 新设计 |
|--------|--------|
| 三档横比同一问句，只验「有对照表 + 1378」 | **必须验可比公司A职能分项**（销售 946、运营 242），对齐 `personnel_compare_sanqi_table_incomplete` gate |
| 深度档 poll 在「不完整对照表」时误判 `streamDone` | `poll_state.js` 在可比公司A销售/运营仍「证据未覆盖」时**继续等** structured replace |
| 单条「可比公司A研发 deep」与横比数据源重叠 | 拆成 **B 组 KB 切块可达性**（员工专节 / 研发专节 / YYCQ excel） |
| Hermes 错稿（139 人、22.6 倍、英文过程稿）偶过检 | **拒收清单**写入 validate；主气泡不得含英文编排泄漏 |
| CDP 后台 tab 用户看不见 | **推荐 MCP `user-chrome-devtools`** + `bringToFront`；CDP runner 须先开可见调试 Chrome |

## 3. 用例矩阵（8 条）

定义见 `backend/scripts/finance_matrix_personnel_cases.py`。

### A 组 · 横比结构化终稿（核心产品验收）

同一业务问句，验 **Tier 路径不同、终稿标准相同**：

| ID | 档位 | 问句 | 必须出现在主气泡 |
|----|------|------|------------------|
| A1 | 快速 | 对比分析YYCQ和可比公司A25年的人员结构 | 对照表 + 可比公司A销售 **946**、运营 **242**、研发 **1378**；YYCQ研发 **70** |
| A2 | 标准 | 同上 | 同上 + Tier 1 完成行 |
| A3 | 深度 | 同上 | 同上 + Tier 2 完成行；trace 可有 Hermes 过程稿，**主气泡不得**停留不完整表 |

**禁止通过**：可比公司A销售/运营列为「证据未覆盖」；139 人总员工当YYCQ规模；`22.6 倍`；英文 `Let me search` 占主气泡。

### B 组 · KB 切块可达性（支撑 gate 的数据源）

| ID | 档位 | 问句 | 验收锚点 |
|----|------|------|----------|
| B1 | 快速 | 可比公司A2025年员工数量、专业构成及教育程度 | **946**、**242**、3138 或「销售人员」表行 |
| B2 | 快速 | 可比公司A2025年研发人员情况 | **1378**、43.91% |
| C1 | 快速 | YYCQ2025年1.1信息-人员 | **70**、61、33.15、45.85（excel 分项） |

> B 组失败时，先修检索 fan-out / 节选（`员工数量、专业构成` 专节），再跑 A 组。

### D 组 · 问法变体（检索与口径）

| ID | 档位 | 问句 | 验收重点 |
|----|------|------|----------|
| D1 | 标准 | 对比YYCQ和可比公司A2025年销售与运营人员规模 | 对照表或并列叙述含 **946**、**242** |
| D2 | 快速 | 对比YYCQ与可比公司A2025年研发人员数量 | 双侧研发（1378 / 70），**不得**错归属 |

## 4. 通过标准（代码对齐）

实现：`finance_matrix_personnel_validate.py` + `finance_matrix_browser_validate.py`。

### 4.1 横比（A / D1）

1. `personnel_compare_has_core_table` — 对照表 ≥3 职能行  
2. `personnel_compare_sanqi_table_incomplete` 为 **false**（销售/运营非「证据未覆盖」）  
3. 正文含锚点：**946**、**242**、**1378**、YYCQ研发 **70**  
4. 无 `personnel_compare_reply_misattributed`（139/22.6 倍等）  
5. 无 `分主体证据摘要`、无 excerpt dump-only  
6. 深度档：`personnel_reply_has_analysis` + KB 调用计数 ≥1（trace 或 stats）

### 4.2 单主体（B / C）

- **B1**：`946` 与 `242` 至少各出现 1 次  
- **B2**：`1378` 或 `1,378`  
- **C1**：`70` 与 `1.1信息-人员` 或分项字段  

### 4.3 流式完毕（poll）

`poll_state.js` 对横比问句：

- 仅有「人员结构对照」但可比公司A销售/运营仍「证据未覆盖」→ **`streamDone=false`**（等 gate replace）  
- `Orient-G 正在综合终稿` 且对照表不完整 → 继续 poll

