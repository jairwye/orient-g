# Evidence Pack + Tier 0–2 实施计划

**Goal:** 多 query 检索 → Evidence Pack → Tier 0/1/2 路由；标准模式默认 Tier 0（本地综合），复杂/缺项升 Hermes。

**Design:** [1.2.3.b-agent-evidence-pack-tiers.md](../features/1.2.3.b-agent-evidence-pack-tiers.md)

## File map

| 文件 | 职责 |
|------|------|
| `backend/services/kb_retrieval_plan.py` | **新建** task_type + 子 query 计划 |
| `backend/services/evidence_pack.py` | **新建** pack 构建、coverage、gaps |
| `backend/services/kb_retrieve_pack.py` | **新建** 多 query ask + 合并 |
| `backend/services/agent_kb_prefetch.py` | 调用 retrieve_pack；注入 pack |
| `backend/services/agent_kb_router.py` | Tier 路由；`agent_tier` 映射 |
| `backend/services/agent_kb_fast_path.py` | system 文案；SSE `agent_tier` |
| `backend/routers/agent.py` | 透传 pack 元数据 |
| `backend/services/ai_interaction_kb.py` | 对话页多 query + pack |
| `backend/routers/ai_interaction.py` | 对话 RAG 走 pack 路径 |
| `backend/config.py` | `HERMES_AGENT_KB_MULTI_QUERY` 等 |
| `docs/hermes.md` | Tier 1/2 契约 |
| `specs/features/1.2.3-agent-kb-router-design.md` | 增补 Tier 交叉引用 |
