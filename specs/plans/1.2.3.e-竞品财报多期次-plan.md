# 竞品财报多期次 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将竞品财报从「全局单例 Snapshot」升级为 **多期次 edition**；侧栏始终打开 **current**；页内可切换含 **2025 年报**；财务后台按期次上传并设置最新；纵向按 `has_vertical` 开关（默认 26H1 关、25 年报可留）。

**Architecture:** `{upload_dir}/competitor/editions/{edition_id}/` + `current.json` → FastAPI（edition 感知）→ Next.js `/competitor` + `/competitor/e/[editionId]`。

**Tech Stack:** FastAPI、pytest、Next.js App Router、既有 competitor 前端组件

**Design:** [1.2.3.e-竞品财报多期次.md](../features/1.2.3.e-竞品财报多期次.md) · **UI:** [1.2.3.e-竞品财报多期次-ui.md](../ui/1.2.3.e-竞品财报多期次-ui.md) · **前置:** [1.2.3.c](../features/1.2.3.c-竞品财报可视化.md)

**Spec 同步：** 实现中若调整入口/存储/API/纵向策略，**必须先改 feature/UI/api-contract，再改本 plan 勾选与代码。**
