## 1. 自动化（pytest / Jest）

在项目根执行：

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests/test_kb_retrieval_plan.py backend/tests/test_evidence_pack.py backend/tests/test_evidence_pack_table_facet.py backend/tests/test_kb_retrieve_pack.py backend/tests/test_kb_retrieve_pack_tables.py backend/tests/test_kb_retrieve_answer.py backend/tests/test_agent_kb_router.py backend/tests/test_kb_ask_budget.py backend/tests/test_kb_cost_detail_pack.py backend/tests/test_ai_interaction_kb_pack.py backend/tests/test_hermes_tool_policy.py -q
```

```powershell
cd frontend; npm test -- --testPathPatterns="agentTraceUtils|chatEvidencePack" --watchAll=false
```

| 用例文件 | 覆盖点 |
|----------|--------|
| `test_kb_retrieval_plan` | 任务类型、子 query 计划 |
| `test_evidence_pack` | coverage、gaps、Tier 判定辅助 |
| `test_evidence_pack_table_facet` | 表格 citation → facet |
| `test_kb_retrieve_pack` | 多 query 合并（mock） |
| `test_kb_retrieve_pack_tables` | 表格证据并入 pack（mock） |
| `test_kb_retrieve_answer` | 统一入口、`KB_MULTI_QUERY` |
| `test_agent_kb_router` | Tier 0/1/2 路由 |
| `test_kb_ask_budget` | MCP `orientg_kb_ask` 预算 |
| `test_kb_cost_detail_pack` | **integration** 竞品财报费用明细 |
| `test_ai_interaction_kb_pack` | 对话 `rag_pack`、**integration** 文件夹检索 |
| `test_hermes_tool_policy` | Tier 1 system 禁 terminal |

**integration** 需本机 PostgreSQL + 已导入竞品财报25 文件夹数据；无 DB 时可 `-m "not integration"`。

## 2. 一键批跑（推荐）

```powershell
.\scripts\run_acceptance_evidence_pack.ps1
.\scripts\run_acceptance_evidence_pack.ps1 -SkipIntegration   # 无 DB 时跳过 integration pytest
.\scripts\run_acceptance_evidence_pack.ps1 -SmokeOnly         # 仅冒烟
```

## 3. 冒烟脚本（需 backend + 可选 Hermes）

```powershell
.\.venv\Scripts\python.exe scripts\smoke_agent_finance.py --ensure-user
.\.venv\Scripts\python.exe scripts\smoke_agent_finance.py --kb --mode standard
.\.venv\Scripts\python.exe scripts\smoke_agent_finance.py --cost-detail --mode fast
.\.venv\Scripts\python.exe scripts\smoke_agent_finance.py --huaqing --mode standard
.\.venv\Scripts\python.exe scripts\smoke_agent_finance.py --chat-rag
```

| 参数 | 预期 |
|------|------|
| `--kb` | `kb_prefetch=true`；有 `evidence_pack` 或 citations |
| `--cost-detail` | `task_type=breakdown`；citations 含费用附注 doc（有 DB 时） |
| `--huaqing` | 回复含合并利润表金额（如 `100,148`）或损益字段；允许表格内部分「缺少证据」缺项行 |
| `--chat-rag` | `/api/ai-interaction/chat` 返回 `read_mode=rag_pack` |
| `--mode fast` | 标准场景下 `agent_tier=0`、`hermes_used=false`（pack 足够时） |

## 4. 浏览器手测（可选）

1. 登录 `finance_test`，**AI 互动 → 智能体**，选竞品财报25 文件夹。
2. 问：「成本下降主要是怎么实现的，分解成明细的对比」→ 执行过程应出现 pack 摘要；标准模式优先 Tier 0。
3. **对话** Tab 同文件夹问同一问题 → 消息上方 Evidence Pack 摘要条。
4. **深度**模式复杂写库任务 → `agent_tier=2`，Hermes 可用 MCP（非 terminal 编造 KB）。
