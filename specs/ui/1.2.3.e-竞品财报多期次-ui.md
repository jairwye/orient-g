## 1. 设计原则

- 壳层、配色、scroll-snap、ProgressScale：**不另起炉灶**，沿用 1.2.3.c。
- 新增能力仅：**期次识别 + 切换**；避免在第一屏堆第二套导航。
- 实施前 Read `~/.cursor/skills/frontend-design/SKILL.md` Orient-G 约束。

---

## 2. 信息架构

```
侧栏「竞品财报」→ /competitor（current）
页头左侧同一行（shrink-0，窄屏可换行）：标题「竞品财报」+ Ghost 期次切换
  └─ editions.length > 1 时，标题旁一个 Ghost EditionSwitcher
  └─ 选项来自 GET /editions（period_label；按时间新→旧排序；不标注「最新」）
  └─ 仅一期：不显示切换钮，沿用静态 period_label
页头右侧：ProgressScale（flex-1 min-w-0，避免与左侧重叠）
纵向入口（页头或既有链）：仅当选中期次 has_vertical === true
```

### 2.1 路由

| URL | 行为 |
|-----|------|
| `/competitor` | 加载 current；Switcher 选中项 = current |
| `/competitor/e/{editionId}` | 加载该期；非法 id → 空态 + 回 current |
| `/competitor/vertical` | 依赖 edition（query 或与横向同步的上下文）；无纵向则说明页 |

---

## 3. EditionSwitcher

- **形态（Ghost text 为 baseline；统一 listbox，勿用原生 `<select>`，勿用分段控件）：**
  - 仅当 `editions.length > 1` 时显示。
  - **触发钮 baseline：`ghost`。** 弱化文字 `period_label ▾`，无边框、无背景；hover / 展开时提亮为 `text-zinc-300`。菜单紧贴触发钮下方（`top-full`）。
  - 菜单：`EditionMenuPanel`（`bg-zinc-900 border-zinc-800`）；选中项左边线蓝 `#2563eb` + zinc 底。勿蓝分段条，勿「最新」badge。
- **布局：** 标题与切换钮在左侧同一行（`shrink-0`，可换行）；右侧 `ProgressScale` 保持 `flex-1 min-w-0`，与左侧不重叠。
- **排序：** 列表按时间**新→旧**（优先 `uploaded_at`；缺省则 `edition_id` 数字友好降序）。
- **文案：** 展示 `period_label`，不展示原始 `edition_id`（id 可 `title` 提示）。**不**使用「最新」角标/badge（默认路由即 current）。
- **切换：** `router.push`（current → `/competitor`，其它 → `/competitor/e/{id}`）；加载中禁用重复点击；切换后 snap 回到该期默认首屏。
- **无障碍：** 触发钮与 listbox 均有 `aria-label="选择财报期次"`。

---

## 4. 空态与告警

| 场景 | UI |
|------|-----|
| 无任何 edition | 与 1.2.3.c 空态类似，链到 `finance_path` |
| edition 不存在 | 「未找到该期次」+ 按钮回 current |
| 本期无纵向 | 「本期未提供纵向汇析」+ 链回横向；勿 空白 404 |
| 解析 warnings | 沿用 CompetitorWarningsBanner；可标注 edition |

页头须让用户 **一眼看出当前是年报还是半年报**（`period_label`），避免误以为仍是 2025。

---

## 5. 财务后台（展示相关）

- 列表行：period_label、kind 标签（年报/半年报）、「侧栏默认」标记、has_vertical。
- 「设为侧栏默认」：确认对话框（文案：侧栏与无参 `/competitor` 将打开本期）。
- 上传成功：链「打开本期」→ `/competitor/e/{id}`；若刚设为 current 可另链「打开侧栏默认」。

---

## 6. 验收（UI）

1. 侧栏进入后页头 period_label 与 current 一致。
2. 切换到 2025 年报后标签与数据同步；刷新深链不丢。
3. 26H1（has_vertical=false）无纵向入口；25 年报切回后入口出现（若数据在）。
4. 配色/间距与 1.2.3.c 一致，无额外卡片堆砌在 hero。
5. 页头 Ghost 切换：标题旁一个触发钮可打开菜单，与 ProgressScale 无重叠；无「最新」badge；下拉按新→旧。
