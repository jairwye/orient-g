## 1. 信息架构（当前）

### 顶栏

- **第一行**：知识库范围 **chips**（私人 / 部门公共 / 项目公共 / 公司公共等，默认多选可见库）。
- **搜索**：右侧 **图标展开** 输入框（非 v4 稿「搜索占满左」；属已落地变体，改顶栏须先改本文）。
- **动作**：「带到 AI 互动」、进入 **大 PDF 文档包**（`/utils/pdf-knowledge`）等入口在页面内保留（见代码 `buildAiInteractionHref`、路由跳转）。

### 主区（左树右详情）

| 区域 | 行为 |
|------|------|
| **左栏 `KbBrowseTree`** | 按 `kb_kind` 分组；可选 **知识库头**（`selection.kind='kb'`）或 **文件夹**（`kind='folder'`）；支持 `parent_folder_id` 树形；仅文件夹行 + 私人未归档计数提示 |
| **右栏** | KB 头或文件夹上下文；**文档表**（上）+ **文件夹/子级**（下）；私人根级文档仅在右栏「文档」区（`pickPrivateRootDocs` / `isPrivateKbRootSelection`） |
| **批量** | 文件夹视图表头支持全选/取消（`folderBulkCheckState`） |

### 选择模型（已实现）

```ts
type KbSelection =
  | { kind: "kb"; kb_kind: string }
  | { kind: "folder"; kb_kind: string; folder_id: string };
```

## 2. 与历史设计稿的差异（有意保留）

| 项 | v4 稿 | 现状 |
|----|-------|------|
| 顶栏搜索 | 布局 2：第一行搜索 + 动作，第二行 chips | chips 行 + 可展开搜索（右对齐） |
| 左栏高度 | `calc(100vh - …)` 精确占满 | `h-[calc(100vh-320px)]` 近似 |
| 选中文件夹时右栏「文件夹」区 | 方案 B：仅当前夹信息 | 以 `folderViewHeading` / `folderForActions` 为准，见代码 |

以上差异**不构成待定 backlog**；若要对齐 v4 顶栏，单独立项并更新本文。

## 3. 非目标 / 暂无计划项

- 不在本文约束全站设计系统（配色沿用经营数据页 zinc + 蓝强调）。
- **复杂多层级文件夹** UI 随 `parent_folder_id` 已有基础树，未单独做 v4 级「子层级」产品稿。
- 部门公共 **默认文件夹自动创建**（早期 v2 提及）若未在 `ensureDeptDefaultFolders` 全量生效，归 **1.2.0.b 规划 backlog**，非本 UI baseline 阻塞项。

---

## 4. 验收要点（维护用）

- 切换 KB chip 后左树与右栏一致；`403/404` 时错误含后端 `detail`（`formatHttpError`）。
- 私人未归档文档不出现在左树文档行，仅在右栏根级文档区。
- 文件夹 `subtree_doc_count` 与 AI 互动 folder picker 禁用逻辑一致（子树无文档的父夹不可选）。
