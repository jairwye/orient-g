## 1. 设计基线

- **壳层：** 复用 `DashboardLayout`（zinc 深色 + `border-zinc-800`），与经营数据页一致。
- **图表色：** 以 `frontend/app/lib/business_chart_colors.ts` → `BUSINESS_CHART_COLORS` 为主色体系（`#2563eb` 主蓝、`#22c55e` 正向绿、zinc 灰对比）。
- **禁止：** 参考稿中独立紫色 AI 套系作为页面主色；禁止未对齐的全站 redesign。
- **实施前：** Read `~/.cursor/skills/frontend-design/SKILL.md` Orient-G 约束节。

## 2. 页面结构

```
DashboardLayout
└─ main（全宽，满屏沉浸 — 无内层多余 padding）
   ├─ StickyHeader（top-0, z-20）
   │    ├─ 左：竞品财报 + 当前章节标题（随 scroll 更新）
   │    └─ 右：公司筛选 Select（选中时 header 底边公司色 2px）
   ├─ ChapterNav（顶栏横向章节条 + 进度线；**不得 fixed 于视口 left**，避免与侧栏重叠）
   └─ SnapContainer（h-[100dvh] flex-1 overflow-y scroll-snap-type y mandatory）
        ├─ section#sec-01 … #sec-10（min-h-[calc(100dvh-9rem)], scroll-snap-align start）
        └─ 每 section：hero 标题 + lead 导语 + 图表 ChartPanel + narrative 内联引用
```

### 2.1 Scroll-snap CSS（baseline）

Tailwind：外层 `flex h-[100dvh] flex-col overflow-hidden`；滚动区 `flex-1 snap-y snap-mandatory overflow-y-auto`；section `snap-start min-h-[calc(100dvh-9rem)]`；内容区 `px-6 md:px-8 py-12 md:py-16`（与经营数据页间距一致，**无** pl-40 侧栏留白）。

### 2.2 章节导航 ChapterNav

- 位于 **StickyHeader 下方**，横向 pill 按钮 + 底部蓝色进度线（宽度 = 当前章节序号 / 10）。
- `IntersectionObserver` root = SnapContainer ref；点击 → scrollTo 对应 section。
- **章节标签（中文）：** 行业总览 / 综合排名 / … / 风险附录。
- 移动端同组件，横向滚动隐藏滚动条。

### 2.3 Sticky Header

- 默认 `bg-zinc-950/90 backdrop-blur-md border-b border-zinc-800`。
- 选中单公司时：header 底边该公司色 2px（`border-b-2`，色值见 §4）。

### 2.4 动效与叙事（v1 baseline）

- 章节块 `competitor-fade-in`：IntersectionObserver 触发 translateY + opacity（见 `globals.css`）。
- 首段 `kind: narrative` → section **lead** 大字号导语；其余 narrative → 左侧蓝线 `blockquote` 内联（非仅 `<details>`）。
- 偶数屏可选 `competitor-section--elevated` 极淡 radial 背景，增强 scroll 节奏。

## 5. 图表与数据展示规范

### 5.1 通用

- 坐标轴/网格：`stroke-zinc-700`，文字 `text-zinc-500` / `fill-zinc-400`。
- Tooltip：深色浮层 `bg-zinc-900 border border-zinc-700 rounded-md px-3 py-2 text-sm`。
- 正负色：净利/增速正 → `#22c55e`；负 → `#ef4444`（仅语义色，非页面主色）。
- 数值格式：亿元/万元与 MD meta 一致；百分比保留 1 位小数。

### 5.2 按屏（与 feature §2.2 对齐）

| 屏 | 组件 | Recharts / 实现 |
|:--:|------|-----------------|
| 1 | 气泡图 | `ScatterChart`；X 营收 log；Y 净利增速 |
| 1 | KPI 行 | 4 卡 `grid grid-cols-2 md:grid-cols-4 gap-3` |
| 2 | 排名条 | `BarChart` layout=vertical |
| 2 | 雷达 | `RadarChart` 5 轴 |
| 3 | 小多图 | 7+1 grid `LineChart`+`Bar` 组合 |
| 3 | 象限 | `ScatterChart` + ReferenceLine x=0,y=0 |
| 4 | 堆叠条 | `BarChart` stackId 100% |
| 5 | 收入 | v1 分组柱；桑基 v1.1 |
| 6 | 环形 | `PieChart` innerRadius 60% |
| 7 | 费用率 | 堆叠条 + 折线 |
| 8 | 瀑布 | 堆叠 Bar 模拟 |
| 9 | 表格为主 | 窄表 + narrative `<details>` |
| 10 | 热力 | CSS Grid 单元格背景色 |

### 5.3 Narrative（分析段落）

- 来源：snapshot `kind: narrative`。
- **首段** meaningful 文本 → section `lead`（hero 下大字号）。
- **其余** → 图表下方内联 `blockquote`（`border-l-2 border-blue-600/60`）；补充说明可用 `<details>`。

## 8. 财务后台上传区（第四块 card）

> **位置：** 财务后台页面 **第四块**（在「上传经营数据」「股权 bundle」「设置财务后台路径」之后或之间按视觉排布）。**无论 `finance_path` 为 `/finance` 还是自定义 alias，均为同一页面、同一上传能力。**

- 与现有 card 风格一致：`rounded-lg border border-zinc-800 bg-zinc-900/50 p-6`。
- 标题：`上传竞品财报汇析（Markdown）`。
- 说明要点：
  - 接受 `.md`；须含 `sec-01`~`sec-10` 锚点；
  - 上传后解析为侧栏 **「竞品财报」**（`/competitor`）数据，**与当前财务后台 URL 无关**；
  - 样例：`uploads/行业财报汇析-2025年_数据文档_YYCQ版.md`（内网文档）。
- 成功：warnings 列表 `text-amber-400/90`；主按钮「打开竞品财报页 →」链 **`/competitor`**（固定展示入口）。
- 失败：parser 错误 + 锚点/行号。

### 8.1 财务后台 card 顺序（baseline）

1. 上传经营数据 Excel  
2. 上传股权资料包 bundle.zip  
3. **上传竞品财报汇析（Markdown）** ← 新增  
4. 设置财务后台路径  

（第 3、4 块顺序可微调，但竞品 MD 上传 **必须** 在财务后台内、**不得** 单独挂到 `/competitor` 或侧栏。）

## 9. 验收要点（UI）

- [ ] 侧栏「竞品财报」进入后满屏 scroll，无 Dashboard 内层多余 padding 破坏 snap。
- [ ] 进度轴与 header 标题随滚动同步。
- [ ] 8 公司色与 legend 一致；与经营页主蓝不冲突。
- [ ] 空态引导至财务后台（`finance_path` 动态链接）。
- [ ] 自定义 `finance_path` 下财务后台可见竞品 MD 上传 card，上传后 `/competitor` 有数据。
- [ ] 移动端顶栏进度可用。
